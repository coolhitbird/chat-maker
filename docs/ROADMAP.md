# chat-maker-v2 产品路线图

**创建时间：** 2026-03-28  
**最后更新：** 2026-03-28  
**项目目标：** 打造专业级聊天对话生成器，支持多平台、多格式输出

---

## 一、产品定位

### 1.1 使用场景

| 场景 | 描述 | 优先级 |
|------|------|--------|
| **个人创作** | 制作有趣的聊天截图/视频，分享到社交媒体 | ⭐⭐⭐ |
| **商业用途** | 广告创意、营销内容、产品演示、品牌推广 | ⭐⭐⭐ |
| **模板市场** | 用户创建并分享模板（留有API接口） | ⭐⭐ |
| **社区发布** | 优质内容可发布到社区供他人使用 | ⭐⭐ |

### 1.2 目标用户

- 社交媒体内容创作者
- 营销/广告从业者
- 产品经理（原型演示）
- 教育工作者
- 普通用户（趣味创作）

## 四、API 接口预留（模板市场）

### 4.1 接口约定

```typescript
// API 接口约定（未来可扩展为后端服务）
interface TemplateAPI {
  // 获取模板列表
  getTemplates(filter?: TemplateFilter): Promise<Template[]>;
  
  // 获取单个模板
  getTemplate(id: string): Promise<Template>;
  
  // 发布模板（需要登录）
  publishTemplate(template: Template): Promise<string>;
  
  // 点赞/收藏
  likeTemplate(id: string): Promise<void>;
  favoriteTemplate(id: string): Promise<void>;
  
  // 评论
  commentTemplate(id: string, content: string): Promise<Comment>;
}

// 数据结构
interface Template {
  id: string;
  name: string;
  description: string;
  author: UserInfo;
  category: string;        // 如 "娱乐", "营销", "教育"
  platform: string;       // 如 "wechat", "qq"
  thumbnail: string;      // 缩略图
  data: ProjectData;       // 项目数据
  likes: number;
  favorites: number;
  tags: string[];
  createdAt: number;
  updatedAt: number;
}
```

### 4.2 本地存储扩展

```typescript
// LocalStorage 结构
interface LocalStorage {
  'chatmaker-projects': Project[];      // 项目列表
  'chatmaker-current': string;          // 当前项目ID
  'chatmaker-settings': UserSettings;    // 用户设置
  'chatmaker-templates': Template[];     // 收藏的模板
}
```

## 七、风险与依赖 ⚠️

### 7.1 技术风险

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| FFmpeg.wasm 兼容性 | 部分浏览器不支持 | WebAssembly fallback |
| 大量消息性能 | 卡顿/崩溃 | 虚拟列表+懒加载 |
| 图片跨域 | CORS 限制 | 代理服务器/用户上传 |
| 移动端适配 | UI 错位 | 响应式布局 |

### 7.2 业务风险

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 模板版权 | 法律风险 | 用户协议+举报机制 |
| 滥用风险 | 用于诈骗/诽谤 | 水印+使用协议 |
| 性能瓶颈 | 用户流失 | 性能监控+优化 |
