## 技术决策

### 决策 1: 为什么选择 Canvas 渲染？

**问题**: 最初的视频导出使用 html2canvas + DOM 的方式，存在以下问题：
- 用户名和气泡框重叠
- 特殊消息（红包、转账等）显示为普通文字
- 文字位置不在垂直居中
- 气泡框占满一行

**解决方案**: 使用 Canvas 直接渲染，确保与图片导出 100% 一致

### 决策 2: 为什么两个导出方法都用 Canvas？

**原因**: 
- `recordVideo` (Preview 页面调用) 和 `recordVideoWithCanvas` (ExportPanel 调用)
- 统一使用 `renderChatToCanvas` 渲染器
- 确保两种导出方式效果一致

### 决策 3: 图片预加载

**问题**: 视频导出时图片可能未加载完成，导致拉伸或空白

**解决方案**: 
- 导出前预加载所有图片
- 创建 imageCache 传递给渲染器
- 渲染时优先使用缓存图片

## 遇到的问题及解决方案

### 问题 1: 滚动逻辑错误导致画面跳动

**现象**: 内容到了屏幕底部后，滚动直接跳到顶部，然后跳跃

**原因**: 每条消息重新渲染时，滚动位置计算不正确

**解决方案**: 简化滚动逻辑，始终从底部开始显示，不做滚动动画

### 问题 2: 图片拉伸问题

**现象**: 视频中图片变形或显示为空白

**原因**: 图片未预加载，Canvas 绘制时图片还没加载完成

**解决方案**: 
1. 导出前预加载所有图片
2. 使用 imageCache 缓存
3. 渲染时检查缓存

### 问题 3: ArrayBuffer 被 detach

**现象**: `Failed to execute 'postMessage' on 'Worker': ArrayBuffer at index 0 is already detached`

**原因**: FFmpeg writeFile 后 ArrayBuffer 不能再使用

**解决方案**: 每帧都重新获取 blob，不复用 ArrayBuffer
