# chat-maker 设计文档

**创建时间：** 2026-03-21  
**最后更新：** 2026-04-05  
**当前版本：** v2.1.0  
**项目目标：** 开发一个高质量聊天对话生成器，模拟微信/QQ/钉钉等平台的聊天记录，输出图片和视频

---

## 一、项目定位

### 1.1 差异化优势

- 技术架构领先（TypeScript + Vite + Tailwind CSS）
- 多平台支持（微信手机端/电脑端、QQ、钉钉）
- 导出一致性好（Canvas API 直接渲染，预览与导出一致）
- 打字动画视频导出（4 种渲染模式）
- 引用/回复消息支持
- 深色/浅色主题

## 三、技术架构

### 3.1 状态管理

单一 Zustand store（`useChatStore`），所有状态集中管理，每次变更同步写入 localStorage。

### 3.2 主题系统

```
colorSchemes.ts（配色）
    ↓
templates.ts（布局基础值：字号/圆角/头像/内边距）
    ↓
platformFactory.ts（createPlatform 工厂函数）
    ↓
wechat.ts（平台主题实例）
```

### 3.3 渲染双轨

- **预览**：React 组件 + CSS（`ChatContainer.tsx`）
- **导出**：Canvas 原生绘制（`canvasRenderer.ts`）或 DOM + html2canvas（`DOMRenderer.ts`）

### 3.4 引用消息实现

```
用户点击消息列表的 ↩ 按钮
    ↓
MessageList.onQuote(message) → App.setQuoteMessage(message)
    ↓
MessageInput 显示引用提示条
    ↓
用户发送消息时，addMessage({ ..., quote: { messageId, sender, content, type } })
    ↓
ChatContainer.renderQuote(msg) → 气泡内顶部渲染引用块
导出渲染器 drawQuote() / createQuoteHtml() → 同样渲染
```

## 六、版本历史

### v2.1.0（2026-04-05）

**新功能**:
- ✅ 引用/回复消息（完整实现：类型定义、编辑器交互、预览渲染、所有导出渲染器）
- ✅ 文件消息编辑器（FileEditor.tsx）

- ✅ 文件消息视觉优化（白底+边框，区别于灰色背景）

**Bug 修复**:
- ✅ 所有渲染器文件消息显示为文字 → 加 `drawFile()`/`createFileHtml()`
- ✅ DOM 模式无打字动画 → 加 `generateTypingSequence` 逐帧计算
- ✅ DOM 模式自定义头像不生效 → `users` 参数不再被忽略
- ✅ DOM 模式滚动不工作 → 改用 `#dom-messages-wrapper` id 精确定位
- ✅ DOM 模式文字在气泡底部 → `vertical-align:top`
- ✅ 双重 speedMultiplier 错误 → 时间轴用实际 ms 推进
- ✅ 帧捕获速度慢 → `toBlob` → `toDataURL`（同步，快 3-5 倍）
- ✅ 文字偏上 → `textBaseline = 'middle'`，每行中心点绘制
